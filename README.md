GridSync – Distributed Resource Sharing System

A web-based simulation that demonstrates how connected computers can share unused CPU and memory resources to improve overall resource utilization.

Features
Simulated CPU and memory resource monitoring
Resource sharing between connected systems
Resource request and allocation simulation
Real-time system status visualization
Interactive web interface for exploring resource sharing
Tech Stack
Frontend: React, TypeScript
Communication: MQTT, EMQX
Development: VS Code
How It Works
The application simulates multiple connected computer systems.
Each system monitors its available CPU and memory resources.
Systems can request unused resources from other connected systems.
MQTT is used to simulate communication between connected systems.
The application displays resource availability and allocation status.
