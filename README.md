# IoT Organ Donor – Smart Organ Resource Sharing System

A simulation-based web application designed to demonstrate how IoT and AI technologies can support secure and efficient organ donation coordination and resource sharing.

## Features

- Donor and recipient information management
- Simulated IoT-based monitoring and communication
- AI-powered task processing using Gemini API
- Simulated resource matching and coordination
- Interactive dashboard for monitoring system activities
- Real-time status updates within the application

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Gemini API
- AI: Google Gemini
- Deployment: Vercel

## How It Works

1. Donor and recipient information is entered through the web interface.
2. The application processes the provided information through the backend.
3. Gemini API performs AI-powered analysis and task processing.
4. The system simulates matching and coordination between donors and recipients.
5. Results and system status are displayed through the interactive dashboard.

This project is a simulation/prototype developed to demonstrate the concept of using IoT and AI technologies for organ donation coordination. It does not connect to real IoT devices or perform actual organ donation transactions.
